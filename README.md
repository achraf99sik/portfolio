# Portfolio of Achraf Sikal

This repository contains the source code for the personal portfolio of Achraf Sikal, a Full Stack Developer. The portfolio is designed with a futuristic, cyberpunk-inspired theme and showcases his skills, experience, and projects.

## Live Demo

The portfolio is live at [sikal.me](https://sikal.me).

## Technologies Used

*   **Frontend:**
    *   HTML5
    *   CSS3 (with a futuristic, cyberpunk-inspired theme)
    *   JavaScript (for typing animations, smooth scrolling, and other interactive elements)
*   **Deployment:**
    *   GitHub Pages

## Sections

The portfolio is divided into the following sections:

*   **Home:** A hero section with a typing animation that introduces Achraf Sikal.
*   **About:** A brief introduction to Achraf Sikal, his passion for web development, and his educational background.
*   **Experience:** A summary of his work experience as a Full Stack Developer.
*   **Skills:** A list of his technical skills, including frontend and backend technologies, databases, and tools.
*   **Projects:** A showcase of his recent projects, with links to their GitHub repositories.
*   **Contact:** His contact information, including his email address and LinkedIn profile.
